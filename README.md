# Лабораторная работа № 1 по ВПД

Дмитриев Владимир Викторович, М3О-104БВ-26, № 8.

Цель работы — сравнить языки программирования и способы сборки и запуска программ из терминала.

Реализованы программы на C, C++, Python, JavaScript, TypeScript, Java, C#, F#, Go, Rust, Bash, Prolog и Assembler. В каждой использована характерная особенность языка: форматирование, интерполяция, типизация, конвейер или правила Prolog.

Программы выводят приветствия, данные студента и вычисляют ID `М3О-104БВ-26/08` и контрольное значение `304 × 8 = 2432`. Ассемблерная версия выводит только английское приветствие.

Окружение: Raspberry, Ubuntu 26.04, ARM64. Исходники сохранены в UTF-8; кириллица выводится корректно. Для ассемблера используются нативные GNU as и GCC.

Пример вывода C:

```text
Hello to 304 from Vladimir, number 8, group М3О-104БВ-26!
Привет, 304! Это Дмитриев Владимир Викторович, номер 8, группа М3О-104БВ-26!
Student ID: М3О-104БВ-26/08 | Language: C | Control: 2432
```

Все 13 программ проверены. Команды сборки и ручного запуска каждого файла приведены в [RUN.md](RUN.md).

Для последовательной сборки и запуска всех языков: `make run-all` (или просто `make`).
Один язык: например, `make c` или `make python`. Удаление результатов сборки: `make clean`.
